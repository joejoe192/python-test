Q1. Drop null values

5 minutes

The items table has some rows with missing data. A row without a seller_id can't be linked to a seller, and a row without a price can't be used in revenue totals.

Input

items: the 10-row table above.

Write the function drop_nulls(df)

  1. Remove every row where seller_id is null or price is null.
  2. Keep rows that have nulls in other columns. Only these two columns decide.
  3. Print the cleaned table.
  4. Count how many rows were dropped: the number of rows before minus the number of rows after.
  5. Return two values: the cleaned DataFrame and the number of rows dropped.

Then, below the function

  1. Call drop_nulls with items.
  2. Store the two results in variables named clean_df and dropped.
  3. Print how many rows were dropped.

Check your result

  • clean_df has 8 rows.
  • 2 rows were dropped: o6 (no seller_id) and o7 (no price).
  • o5 still appears twice. That is correct: it has no nulls. Duplicates are Q2's job.
  • items still has 10 rows. Your function must not change it.

  4. Print the cleaned table.
  5. Return two values: the cleaned DataFrame and the number of rows removed.

Then, below the function

The variable count = 0 is already written for you.

Q5. Create two tables and load

8 minutes

Save the good items and the rejected rows in Postgres. The staging schema already exists. The two tables below do not exist yet, so your code must create them.

Input

good_df = deduped (7 rows), rejected_df from Q4 (3 rows), and engine (already created at the top of the file).

No primary key: rejected rows may contain duplicates.

Write the function load_items(good_df, rejected_df, engine)

  1. Write the SQL in create_sql that creates both tables, but only if they do not exist. Put staging. in front of each table name.
  2. Open one transaction with the engine. Inside it:
    1. run create_sql
    2. delete all rows from both tables, so a second run does not add the rows again
    3. insert good_df into staging.order_items_clean and rejected_df into staging.order_items_rejected; add the rows to the tables you created (do not replace the tables) and do not write the DataFrame index
    4. count the rows in each table
  3. After the transaction, print Loaded X good items and Y rejected items and return the two counts.

Then, in main()

  1. Call load_items with deduped, rejected_df and engine.
